# 拼音向量搜索使用说明

## 项目概述

拼音向量搜索是一个专门解决语音识别中发音差异导致搜索问题的智能搜索系统。当用户的发音不标准或语音识别存在错误时，传统的精确匹配搜索无法找到正确的结果，而拼音向量搜索通过语义理解和拼音分析，能够准确找到用户真正想要搜索的内容。

## 核心问题

### 语音识别中的发音差异问题

- **标准发音 vs 方言发音**：不同地区的人对同一个字的发音可能存在差异
- **声母混淆**：如 `zh/z`、`ch/c`、`sh/s` 等声母容易被混淆
- **韵母变化**：如 `ing/in`、`ou/uo` 等韵母在不同方言中发音不同
- **多音字问题**：同一个字在不同语境下的读音不同

### 实际案例

| 标准发音 | 错误识别 | 问题类型 |
|---------|---------|----------|
| 周萍 (zhou ping) | 邹萍 (zou ping) | zh → z 声母混淆 |
| 张敏 (zhang min) | 张民 (zhang min) | ing → in 韵母变化 |
| 王红 (wang hong) | 忘红 (wang hong) | 声母模糊识别 |
| 李华 (li hua) | 李华 (li hua) | 标准发音，精确匹配 |

## 技术方案

### 1. 拼音标准化

- **中文转拼音**：使用 `pypinyin` 库将中文文本转换为标准拼音
- **拼音变体生成**：根据常见发音错误生成可能的拼音变体
- **声母韵母映射**：建立声母和韵母的相似度映射表

### 2. 向量化技术

- **BGE嵌入模型**：使用 BAAI/bge-large-zh-v1.5 模型对拼音进行向量化
- **多变体融合**：对标准拼音和所有变体进行向量化，计算平均向量
- **语义相似度**：通过向量相似度计算语义相近程度

### 3. 混合召回策略

1. **精确文字匹配**：优先进行精确的中文文字匹配
2. **拼音向量搜索**：使用拼音向量进行语义相似度搜索
3. **模糊拼音匹配**：基于编辑距离的拼音模糊匹配
4. **结果融合排序**：综合多种匹配结果，按相似度排序

## 使用方法

### 1. 安装依赖

```bash
# 安装拼音处理库
pip install pypinyin==0.51.0

# 安装其他依赖（如果尚未安装）
pip install -r requirements.txt
```

### 2. 快速启动演示

```bash
# 运行完整演示
./scripts/run_pinyin_demo.sh

# 或者直接运行Python脚本
python demos/pinyin_vector_search_demo.py
```

### 3. 编程接口使用

```python
from ragflow_integration.pinyin_vector_search import PinyinVectorSearchEngine

# 创建搜索引擎
search_engine = PinyinVectorSearchEngine(similarity_threshold=0.7)

# 添加可搜索实体
entities = [
    {"entity_id": "person_001", "entity_name": "周萍", "metadata": {"department": "销售部"}},
    {"entity_id": "person_002", "entity_name": "张敏", "metadata": {"department": "技术部"}},
    # ... 更多实体
]

search_engine.batch_add_entities(entities)

# 执行搜索
results = search_engine.search("邹萍", top_k=5)

# 处理结果
for result in results:
    print(f"找到: {result.entity_name}")
    print(f"相似度: {result.similarity_score:.3f}")
    print(f"匹配类型: {result.match_type}")
```

## 核心组件

### 1. PinyinNormalizer - 拼音标准化器

负责中文到拼音的转换和拼音变体生成：

```python
from ragflow_integration.pinyin_vector_search import PinyinNormalizer

normalizer = PinyinNormalizer()

# 基础转换
pinyin_text = normalizer.text_to_pinyin("周萍")  # "zhou ping"

# 生成变体
variants = normalizer.generate_pinyin_variants("周萍")  
# ["zhou ping", "zou ping", "z ping", ...]

# 相似度计算
similarity = normalizer.calculate_pinyin_similarity("zhou ping", "zou ping")
```

### 2. PinyinVectorSearchEngine - 拼音向量搜索引擎

核心搜索引擎，提供完整的搜索功能：

```python
# 初始化（可配置相似度阈值）
engine = PinyinVectorSearchEngine(similarity_threshold=0.6)

# 添加实体
engine.add_entity("emp_001", "周萍", {"department": "销售部"})

# 搜索
results = engine.search("邹萍", top_k=5, enable_fuzzy=True)

# 获取统计信息
stats = engine.get_statistics()
```

### 3. 搜索结果结构

```python
@dataclass
class PinyinSearchResult:
    entity_id: str          # 实体ID
    entity_name: str        # 实体名称
    pinyin_text: str        # 标准拼音
    similarity_score: float # 相似度分数 (0-1)
    match_type: str         # 匹配类型: 'exact', 'pinyin', 'fuzzy'
    original_query: str     # 原始查询
    pinyin_query: str       # 查询拼音
```

## 配置参数

### 主要参数

- **similarity_threshold**: 相似度阈值 (默认: 0.7)
  - 越高越严格，返回结果越精确
  - 越低越宽松，返回结果越多

- **embedding_model**: 嵌入模型
  - 默认使用 BGE-large-zh-v1.5
  - 支持自定义模型

### 拼音映射配置

可以根据实际使用场景自定义声母韵母映射：

```python
# 在 PinyinNormalizer 中自定义映射
normalizer = PinyinNormalizer()

# 添加自定义声母映射
normalizer.initials_mapping.update({
    'zh': 'z',    # 自定义声母映射
    'ch': 'c',
})

# 添加自定义多音字
normalizer.polyphone_dict.update({
    '新增字': ['读音1', '读音2'],
})
```

## 性能优化

### 1. 批量操作

- 使用 `batch_add_entities()` 批量添加实体
- 使用 BGE 模型的批量编码功能

### 2. 内存优化

- 向量结果使用 numpy 数组存储
- 支持向量的保存和加载

### 3. 搜索优化

- 三阶段搜索策略：精确→向量→模糊
- 结果去重和智能排序

## 注意事项

### 1. 模型依赖

- 需要下载 BGE 模型（约1GB）
- 首次运行会自动下载模型

### 2. 性能考虑

- 向量搜索需要一定的计算资源
- 建议在GPU环境下运行以获得更好性能

### 3. 数据质量

- 实体名称应该规范，避免包含特殊字符
- 建议对实体数据进行预处理和清洗

## 故障排除

### 常见问题

1. **模型下载失败**
   ```bash
   # 设置代理或镜像
   export HF_ENDPOINT=https://hf-mirror.com
   ```

2. **依赖安装失败**
   ```bash
   # 升级pip
   pip install --upgrade pip
   # 使用国内镜像
   pip install -i https://pypi.tuna.tsinghua.edu.cn/simple pypinyin
   ```

3. **搜索结果不准确**
   - 调整 similarity_threshold 参数
   - 检查实体数据质量
   - 自定义拼音映射规则
